## 性能范围

Chrome 自动检查使用 SwiftShader 软件 WebGL；截图约 50–55 FPS 只反映测试环境，不能视为 GPU 实机性能指标。最终内置浏览器默认中密度显示约 60 FPS，未采集 GPU 利用率或能耗。代码使用单 draw call、静态缓冲、分辨率上限控制负担；不声称所有设备达到 60 FPS。

低/中/高密度为 12,960 / 35,040 / 62,720。高分屏限制内部像素总量；超宽/竖屏保持透视比例并裁切曲面的横向范围。

- 上线可访问性与 Actions 状态以 GitHub 实际结果为准。

## 复验

npm test 执行无依赖音频测试。npm start 打开本地预览，检查模拟开关及 H/F/空格。tests/browser.cjs 保留本轮自动检查程序；它需要独立安装 playwright 并指定 Chrome 路径，不属于壁纸运行依赖。
