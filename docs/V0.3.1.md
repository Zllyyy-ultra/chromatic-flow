# V0.3.1 full-screen density

The user requested substantially more particles covering the whole screen.

- Default count increased from 35,040 to 110,592 (3.16x). Low/high settings now draw 49,152 / 196,608 points.
- Main formations are enlarged and aspect-aware. A separate moving volume, 60% of the points, is projected from screen coordinates at multiple depths. It remains full-screen during every morph and on wide viewports.
- Field particles retain visible opacity instead of the old faint 12% background specks. Edge wraps occur beyond the visible boundary. Default spread is 75%.
- Density is available directly in the main panel: light / full / starfield. Rendering still uses one draw call and the existing pixel budget; additional vertices increase GPU work, so no universal FPS guarantee is made.

Validation: 7/7 Node tests, 20 browser assertions passed. The render test reads pixels across an 8x6 grid for each of the three formations, requiring visible particles in all 48 tiles including corners. Observed minimum bright-pixel counts per tile: ribbon 1019, vortex 813, nebula/rings 3599 at the test viewport. High-density 196,608-point rendering and context recovery also passed. These are screen-coverage checks, not hardware performance benchmarks.

See tests/visual.html for reproduction. Actual Wallpaper Engine system audio and long-term hardware performance remain unverified.
